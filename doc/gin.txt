*gin.nvim*  Lua Git integration for Neovim

Requires Neovim 0.10+ and Git. No Deno or Denops runtime is required.
This rewrite is in progress. Its reference is vim-gin commit
24cce091cfa32c013bc53cf4ff8f721d6690cf24. See MIGRATION.md in the repository
for implemented behavior, validation evidence, and remaining compatibility work.

Contents ~
    Commands           |gin-commands|
    Arguments          |gin-arguments|
    Actions            |gin-actions|
    Configuration      |gin-configuration|

==============================================================================
COMMANDS                                                        *gin-commands*

:Gin [++wait] [++worktree={path}] {git-arguments}                       *:Gin*
    Execute Git asynchronously and display live output. :silent suppresses
    progress. ++wait waits for completion while servicing proxy requests and
    displaying progress. Successful commands
    emit |GinCommandPost|. ++processor={command} transforms stdout; processor
    failure prevents the success event.

:GinBuffer [++opener={opener}] {git-arguments}                    *:GinBuffer*
    Display Git output in a buffer. :edit reloads it. ANSI Git colors become
    highlights; ++monochrome skips forced Git coloring. Supports ++worktree,
    ++filetype, ++processor, ++emojify, ++enc and ++ff.
    ++diffjump[={revision}] enables diff jumps using the revision and its first
    parent. An omitted or empty revision means HEAD. ++difffold enables folds.

:GinStatus [options] [flags] [-- pathspecs]                       *:GinStatus*
    Display status using Git's untracked-file settings. Use --untracked-files=all
    (or -uall) to list individual files inside untracked directories. << stages
    the selected lines; >> unstages them. dd opens a smart diff, pp opens patch
    panes, !! opens conflict panes, == stashes the selection, <CR> opens the
    working file, and yy yanks its absolute path.
    -uno hides untracked files; -unormal groups untracked directories. Put
    option-like paths after --, for example :GinStatus -- -uall.

:GinBranch [options] [flags] [patterns...]                       *:GinBranch*
    List branches. <CR> switches branches and yy yanks the branch name.
    The default display uses Git's color.branch.* settings.
    Color atoms in --format render as highlights; --no-color disables them.
    --abbrev={n} and --no-abbrev control the default commit column and its yank.
    --no-verbose shows names only; --no-verbose -v shows abbreviated details.
    Actions include new, move, delete, worktree, merge, rebase, and log.
    Remote deletion deletes the remote ref. Use the action help to inspect
    available variants before running destructive actions.

:GinLog [options] [flags] [revision] [-- paths...]                   *:GinLog*
    Display commit history. <CR> shows the commit; yy yanks its hash.
    Actions include cherry-pick, revert, reset, tag, fixup, merge and rebase.
    Paths are repository-relative. ++emojify renders GitHub emoji names.

:GinReflog [options] [flags] [ref]                               *:GinReflog*
    Display reflog history with the implemented GinLog actions.

:GinStash [options] [flags]                                      *:GinStash*
    List stashes. <CR> shows the stash; yy yanks its ref. apply, pop, and drop
    act on the first selected entry. apply:index and pop:index restore the
    index as well. Supports ++emojify.

:GinTag [options] [flags] [patterns...]                             *:GinTag*
    List tags. <CR> shows the tag; yy yanks its name. Actions include delete,
    switch:detach, and yank:commit. Supports ++emojify.
    Color is disabled by default; --color=always enables color atoms in --format.

:GinEdit [options] [commitish] {path}                              *:GinEdit*
    Open the index version by default, or an immutable revision if commitish
    is supplied. Paths are repository-relative. :write on an index buffer
    updates the index while preserving the working file. Supports ++worktree,
    ++opener, ++enc and ++ff.

:GinDiff [options] [flags] [commitish] [-- paths...]               *:GinDiff*
    Display a comparison; --cached compares the index. Revision ranges are
    supported. Paths are repository-relative. <CR> jumps to the matching side
    of a changed line, g<CR> to the old side, and <C-g><CR> to the new side.
    zc/zo close/open file folds. Supports ++worktree, ++opener, ++processor,
    ++enc and ++ff.

:GinPatch [++no-head] [++no-worktree] [path]                      *:GinPatch*
    Open HEAD, index and working-file diff panes, focusing the index. Path is
    relative to cwd and defaults to the current file. In the index pane, dol
    gets a HEAD hunk, dor gets a working-file hunk, and :write saves the index.
    do gets the right pane if present, otherwise the left. dp puts the hunk
    into the working pane. Other panes use do/dp with the index where possible.

:GinChaperon [++no-ours] [++no-theirs] [path]                  *:GinChaperon*
    Open theirs, working-file and ours conflict panes, focusing the working
    file. Path is relative to cwd and defaults to the current file. Conflict
    blocks are removed from the buffer. dol/dor get hunks from theirs/ours;
    do prefers ours. Side panes use dp to put hunks into the working file.
    Write the resolved file, then stage it explicitly.

:[range]GinBrowse [flags] [revision] [path]                     *:GinBrowse*
    Open a hosting URL, defaulting to the current file. --no-browser prints
    it; ++yank=a copies it to register a. Supports --home, --commit,
    --permalink, --remote={name}, ++repository and ++worktree. GitHub, GitLab
    and Bitbucket routes are supported. --pr finds GitHub PR URLs from merge
    messages and local ancestry, using remote HEAD or main as fallback.

:GinBlame [options] [commitish] {path}                           *:GinBlame*
    Open synchronized attribution, committed content and commit details.
    <CR> follows the line's source commit and historical filename; selecting
    that commit again visits its parent. <C-O>/<C-I> traverse visited revisions.
    Source and attribution windows use winfixbuf to prevent accidental buffer
    replacement. Reloading source or attribution refreshes the panes.
    Closing a pane closes its companions. Supports ++worktree, ++opener,
    ++enc, ++ff and ++emojify.
    Emoji rendering affects commit summaries in attribution and details,
    preserving authors, message bodies and literal source text.

:GinCd                                                            *:GinCd*
:GinLcd                                                          *:GinLcd*
:GinTcd                                                          *:GinTcd*
    Change global, window-local or tab-local cwd to the buffer's repository.

==============================================================================
ARGUMENTS                                                       *gin-arguments*

Commands locate the repository from the current buffer, then cwd.
++worktree={path} explicitly selects a repository where supported.
Use Vim command argument syntax: escape spaces with backslashes. %:p expands
the current filename. The -- separator ends Gin's ++option parsing, so paths
such as ++wait remain Git arguments after it. Filename expansion still applies.
Example: >
    :GinStatus
    :GinEdit HEAD src/main.lua
    :GinDiff --cached -- src/main.lua
    :GinBuffer ++opener=split log --oneline -10
<
require('gin.util').reload([bufnr])                           *gin-util-reload*
    Schedule :edit for the specified buffer (default or 0: current buffer).
    A buffer hidden in the current tab reloads once on its next BufEnter.
    Reloading another visible buffer restores the original window afterward.
    Displaying windows retain their cursor and scroll positions where possible.
    Unsaved changes are retained and :edit failures are reported with
    vim.notify(). Requests for buffers wiped before execution are ignored.
    Listing views use this deferred reload after GinCommandPost; GinStatus also
    uses it after file writes. Hidden views refresh on their next entry.

require('gin.util').expand(expr)                              *gin-util-expand*
    Expand a Vim filename expression. For GinEdit, GinDiff and file-filtered
    GinLog buffers, return the first represented file's absolute path. Views
    without a file path and unrecognized URI data retain their expanded name.
    Commands use the same function for % and # arguments.

require('gin.util').worktree([path])                        *gin-util-worktree*
    Return the repository worktree for an explicit path, or use the current
    buffer and window directory when omitted. Raise an error if no repository
    can be found. An invalid explicit path does not fall back to the current
    repository.

Supported openers are edit, split, vsplit, tabedit and pedit. Availability and
pane layout depend on the command. ++enc/++encoding and ++ff/++fileformat select
decoding on commands that support them. ++processor accepts a command with its
arguments escaped as one Gin argument.
For output views, GinEdit and either Blame pane, :edit ++enc={encoding}
++ff={format} overrides the URI decoding settings for that read. Ordinary
reload uses the URI defaults.

:read {URI} inserts output for gin://, ginedit://, gindiff://, gintag://,
ginlog://, ginreflog:// and ginstash:// buffers. Obtain the URI from an existing
Gin buffer's name. Reads support line addresses and decoding without changing
the destination buffer's encoding or fileformat. URI compatibility is still
being audited; avoid constructing URIs by hand.

==============================================================================
ACTIONS                                                           *gin-actions*

In status, branch, tag, log, reflog and stash views:
    a       Choose an action, with completion.
    .       Repeat the chosen action on the current selection.
    ?       Show action help.

Actions use <Plug>(gin-action-{name}) mappings. Available actions depend on the
view. help:all lists detailed variants. echo prints selected candidate metadata
as JSON. Normal mode selects the current line; visual mode selects a range.
User-defined global and buffer-local action mappings appear in discovery.

Lua callers can use: >lua
    local action = require('gin.action')
    local buf = vim.api.nvim_get_current_buf()
    action.list(buf)                   -- sorted action names
    action.call(buf, 'echo', { 1, 2 }) -- inclusive, one-based line range
<
In an initialized Gin action view, use action.define(buf, name, callback).
The callback receives (buf, range). action.range() returns a copy of the current action selection.
Treat other module internals as subject to change during the migration.

==============================================================================
CONFIGURATION                                               *gin-configuration*

Set globals before opening a view. Argument settings are lists of strings:
    g:gin_{kind}_default_args       Used when no explicit arguments are given.
    g:gin_{kind}_persistent_args    Prepended to default or explicit arguments.

Kinds: branch, browse, chaperon, diff, edit, log, reflog, patch, stash, status,
and tag. GinBlame shares the edit settings, matching the pinned upstream.
Both settings are validated even when explicit arguments are given.
Example: >lua
    vim.g.gin_status_default_args = { '--short' }
    vim.g.gin_browse_persistent_args = { '--no-browser' }
<
Set g:gin_{kind}_disable_default_mappings = 1 to disable default keys for status,
branch, tag, log, reflog, stash, diff, buffer, blame, patch or chaperon.

                                             *g:gin_difffold_prefixes*
Customize fold labels with added, deleted, modified and renamed keys. Missing
keys use ASCII defaults. Presets are available in Lua: >lua
    vim.g.gin_difffold_prefixes = require('gin.difffold').presets.nerdfont
<
The plugin also publishes g:gin#difffold#prefixes_ascii and
g:gin#difffold#prefixes_nerdfont.

Set g:gin_chaperon_supplement_disable = 1 to hide supporting commit logs.
g:gin_chaperon_supplement_height controls their height (default 10).
g:gin_browse_aliases configures hosting aliases for browse URLs.

==============================================================================
EDITOR AND PROMPTS                                                 *gin-proxy*

Asynchronous Gin commands open Git editor requests in a new tab. Buffer-local
:Apply writes the file and continues Git; :Cancel rejects the request. Quitting
asks whether to apply. Git credential prompts use masked Neovim input.

    g:gin_proxy_editor_opener            Choose another supported opener.
    g:gin_proxy_disable_editor           Set to 1 to retain Git's editor.
    g:gin_proxy_disable_askpass          Set to 1 to retain Git's askpass.
    g:gin_proxy_apply_without_confirm    Set to 1 to apply on quit directly.

With filetype plugins enabled, gitcommit/gitrebase buffers get :Accept (:wq)
and :Cancel (:cq) aliases unless already defined. Disable them with
g:gin_proxy_disable_accept_and_cancel_aliases = 1. Proxy buffers retain their
request-specific :Apply and :Cancel. ++wait services proxy requests while waiting;
see |gin-limitations| for the remaining interactive-editing validation limit.

==============================================================================
STATUSLINE                                                     *gin-components*

Lua functions return cached strings and update asynchronously:
    require('gin.component.branch').ascii() / .unicode()
        Branch and upstream.
    require('gin.component.traffic').ascii() / .unicode()
        Ahead/behind counts.
    require('gin.component.worktree').name() / .full()
        Repository path.

Listen for |GinComponentPost| to redraw the statusline.

==============================================================================
EVENTS                                                             *gin-events*

                                                        *GinCommandPost*
User GinCommandPost
    Successful commands schedule this event 100ms after the latest completion.
    Completions within that interval are combined into one event. ++wait waits
    for the command and processor; the event and view refresh happen afterward.
    List views and components use it to refresh. Gin retains eventignore=all
    from dispatch even if the option is restored before asynchronous completion.

                                                        *GinComponentPost*
User GinComponentPost
    Emitted when asynchronous component data is ready.

==============================================================================
LIMITATIONS                                                   *gin-limitations*

The migration is incomplete. See MIGRATION.md for the detailed audit status.
Git processes and output processors have no implicit time limit. Gin ++wait
and synchronous buffer operations service proxy requests and progress while
waiting; manual interactive editing during the wait remains unverified.

The upstream g:gin_log_parse_pattern, g:gin_reflog_parse_pattern,
g:gin_tag_parse_pattern and g:gin_stash_parse_pattern settings are not yet
implemented. They accept JavaScript regular expressions upstream. Lua patterns
are not a compatible substitute. Custom indicator APIs, remaining display
options, URI compatibility and legacy Vimscript APIs also remain under audit.
